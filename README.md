## Featured project

### [JobLens](https://github.com/Darren-dev141/joblens) — is this job posting still real?

An evidence-first audit of job postings. JobLens follows each listing back to the employer's own careers site and records what it finds — a working apply link, an expired post, or an honest "couldn't verify."

- **Live demo:** [darren-dev141.github.io/joblens](https://darren-dev141.github.io/joblens/) — runs fully in the browser, works offline
- **Pilot (10 postings, Oct 2026):** 2 confirmed employer apply links · 1 already expired · 4 unverifiable either way, reported as unverified — never dressed up as "fake jobs"
- Half the sample independently re-reviewed; every claim opens its evidence trail; CSV export
- Python · data validation · vanilla HTML/CSS/JavaScript, zero dependencies
